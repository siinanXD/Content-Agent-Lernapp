# SIN-226 — Planer plant auch Content

- **Links:** Linear [SIN-226](https://linear.app/sinan-kahraman/issue/SIN-226/ap-26-planer-plant-auch-content-abdeckung-je-berufmodul-neue-berufe); Supabase [PostgREST](https://supabase.com/docs/guides/api) (Zählung und Paging über `Range`); Vorgänger `scripts/autonomy/planner.mjs` (SIN-223, SIN-227)
- **Entscheidung:** (1) Neues Modul `scripts/autonomy/content-metrics.mjs`: Abdeckung je Map und Modul (Soll = Summe `blocks[].units`, Ist = Zeilen in `units` mit Slot-ID `<block>-u<n>`), Bestehensquote je Modul aus `question_quality_latest`, Kosten und neue Einheiten aus `docs/ops/content-runs/*.json` (Dry-Runs zählen nicht), Quellen-Monitor-Meldungen aus offenen Linear-Issues mit „Quellen-Monitor“ im Titel. (2) Die Regeln aus dem Issue laufen als reine Funktion `contentRuleHints` und stehen als Vorschläge im Prompt-Abschnitt „Content“; das Modell legt Content-Issues nur dafür an. (3) `planner.mjs --context` zeigt die Abdeckungstabelle samt Einheiten neu diese Woche und Kosten als Wochenbericht. Keine eigene Eigenbau-Abhängigkeit, kein neues Paket.
- **Annahmen:** Maps = `docs/content/*.json` ohne `*-curriculum*` und `sources.lock.json`. Geteilt ist nur M0 (D-40), gezählt in der ersten MAF-Map (Metall); dessen Einheiten liegen im Metall-Kurs. Kurs je Map: Metall über die feste Kurs-ID, die übrigen MAF-Kurse über das Schlüsselwort aus der Migration AP-20, `indkfl` über „Industriekaufmann“; fehlt ein Kurs, zählt die Map 0 %. Als veröffentlicht gilt jede Zeile in `units` (es gibt keine Statusspalte). „Verworfene Fragen“ = Fragen, deren letzte Bewertung nicht bestanden ist. „Fabrik hängt“ = die letzten 2 Live-Läufe mit 0 bestandenen Einheiten. „Höchstens 1 neuer Beruf pro Monat“: `lastNewProfessionAt` wird noch nicht gespeichert, im Prompt begrenzt der Hinweis es auf 1; die Funktion kann den Zeitpunkt schon prüfen. Aktive Lernende = verschiedene `anonymous_id` je Kurs (keine Personendaten). Ohne Supabase-Zugang steht „nicht verfügbar“ und die Abdeckung zeigt 0 %, im Prompt als „nicht als Lücke werten“ markiert. Die Abdeckung der Nicht-Metall-Maps ist heute vermutlich 0 %, die Regel „alle über 90 %“ greift also erst später.
- **Warum:** Der Planer sah nur die Gesamtzahl der Einheiten; mit Abdeckung je Modul kann er Qualitätsprobleme und neue Berufe planen, ohne der Content-Fabrik Lücken abzunehmen. Reine Funktionen lassen sich mit Fixtures testen, ohne Supabase.
